# Редизайн сайта УрФУ — конкурсный прототип

Новый знак, новая структура и 161 страница: главная, 14 страниц разных типов, фирменный стиль, описание концепции и 404, а ещё страницы всех направлений, институтов и разделов меню, собранные из данных. Работает каждая кнопка.
Концепция для жюри: `docs/urfu-koncepciya.pdf` (она же — страница `koncepciya.html`).

## Как посмотреть

Онлайн: **https://kk228m10-sys.github.io/urfu-redesign/** — GitHub Pages, работает как настоящий сайт.

```
npm install          # один раз
npm run dev          # http://localhost:4321, пересборка и автообновление при правках
```

Без сервера: откройте `dist/index.html` двойным кликом. Шрифты, поиск и данные встроены, сайт работает даже с флешки без интернета.

## Картинки и видео

Иллюстрации и видео сгенерированы нейросетью по промптам из `docs/AI-PROMPTS.md`, фото зданий — настоящие, с Wikimedia Commons (авторы — в подвале каждой страницы, «Фото и лицензии»). Где AI-картинка изображает реальное место (обсерватория, новый кампус), на ней стоит пометка «Иллюстрация».

1. Исходники — в `assets/incoming/` (в git не попадают). Файл находится по имени из промпта, даже если в названии есть лишнее: «### hero-stairs.jpg — 32.png».
2. `node tools/images.mjs` — ч/б, контраст, зерно, WebP в нескольких размерах. Вырезанным фигурам (`cutout` в `assets/images.json`) сначала убирается белый или «шахматный» фон: `tools/cutout.py`, нужен Python с Pillow, numpy и scipy.
3. `node tools/video.mjs` — видео из `videos` в `assets/images.json`: кадрирование, тот же ч/б, бесшовная петля, без звука, постер.
4. `npm run build` (или просто работающий `npm run dev`) — всё встанет на свои места.

План Втузгородка на странице «Где аудитория» снят со схемы корпусов (`assets/incoming/campus-map.jpg`): `tools/trace-plan.py` → `tools/gen-plan.mjs` → `build/campus-plan.mjs`.

## Инструменты

| Команда | Зачем |
|---|---|
| `node tools/measure.mjs` | после правки крупных заголовков: измеряет их ширину, чтобы они вписывались в строку |
| `node tools/check-js.mjs` | проверяет все страницы на ошибки JavaScript (нужен `npm run dev`) |
| `node tools/shots.mjs` | скриншоты первых экранов для концепции |
| `node tools/pdf.mjs` | пересобирает `docs/urfu-koncepciya.pdf` |
| `node tools/images.mjs`, `node tools/video.mjs` | обработка картинок и видео из `assets/incoming` |

## Как показать жюри

- Ссылкой: перетащите папку `dist` на app.netlify.com/drop — через минуту будет публичный адрес. Или GitHub Pages.
- Если жюри нужен именно Figma: плагин html.to.design превращает страницу по ссылке в редактируемые слои Figma.
- На защите: `dist/index.html` с флешки, интернет не нужен.

## Сверить перед защитой

- Фото корпусов на «Где аудитория» — Wikimedia Commons (авторы в подвале страницы). Проверить, что «Здание ВШЭМ (ФЭУ)» — это корпус И, а «Здание УралЭНИН» — корпус Т; у Э, М и СП фото нет, там только план.
- Корпуса и переходы на плане — по присланной схеме. Что в каких корпусах (`build/rooms.mjs`): Э и Т — УралЭНИН, М и Мт — ИНМиТ, И — ИнЭУ (по списку корпусов 2011 года); у СП владелец неизвестен; адреса М и СП не указаны. Розовые линии схемы показаны как переходы.
- Коуровская обсерватория на «Науке» пока с AI-иллюстрацией: на Wikimedia Commons есть настоящие фото (Д. Вибе, CC BY-SA 4.0) — их можно поставить.
- Сокращения и краткие описания институтов (`src/data/institutes.json`).
- Правило «до пяти направлений в одном вузе» и даты приёма (`build/pages/postupit.mjs`).
- Время пар и пример расписания (`build/pages/raspisanie.mjs`) — это пример.
- Даты истории (`build/pages/istoriya.mjs`) — по Википедии; лучше подтвердить в музее УрФУ.
